S.A.B.R.E.E. ENRICHMENT ACADEMY — Bootstrap 5 website template

OPEN
1. Extract this ZIP into a folder.
2. Open index.html in a modern browser.
3. Internet access is needed for Bootstrap 5 and Bootstrap Icons CDN assets.

IMPORTANT
This is a static front-end template. Contact forms, logins, donations, and data collection are not implemented. Review all text, names, titles, image permissions, and official links before publishing.

LINK SETTINGS:
- All anchor links use href="#" placeholders; no original-site destinations remain.
- Footer includes social icons and editable email, phone, and mailing-address placeholders.
- Replace the placeholders with verified official contact details and social URLs before launch.
